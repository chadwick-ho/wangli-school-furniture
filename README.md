# WangLi — Arabic school furniture website

Arabic website preview for WangLi school furniture, serving distributors and project supply companies in the Middle East and Africa.

- 30 static pages and 12 product categories.
- Original product photographs, catalog extracts and a web reading copy of the supplied English catalog.
- Arabic RTL layout; model numbers and dimensions preserve their reading direction.
- Contact links lead to the existing WangLi website and Alibaba store.

This public repository contains the website files only. WordPress software, theme installation packages and internal SEO planning files are maintained separately.

The site is deployed with GitHub Pages from the root of the `main` branch. It is currently a preview with `noindex`; the final domain, contact details and outstanding product specifications are still being confirmed.
