# WangLi — Arabic school furniture website

Live preview: https://wangliarabia.com/

Arabic school furniture website for distributors and project supply companies in the Middle East and Africa.

- 40 pages, including 12 product categories, a Blog with three Arabic articles, factory gallery and company document library.
- Original WangLi logo in the header and an orange W website icon.
- Product photographs, a public catalog, an Arabic specification spreadsheet and two blank inquiry templates.
- Arabic RTL layout and model/dimension reading direction preserved.
- HTTPS-domain canonical URLs, sharing metadata, breadcrumbs and content-matched structured data.
- Contact links lead to the existing WangLi website and Alibaba store.

This repository contains public website files only. WordPress software, theme packages and internal planning files are maintained separately. The static site has no WordPress backend or inquiry form service.

GitHub Actions builds Markdown articles on each main-branch push and deploys the website-only `_site` artifact to Pages. See [BLOG_EDITING.md](BLOG_EDITING.md) for article instructions. WordPress is not required for this deployment.

The 25 reviewed core, category, Blog, article, factory and document URLs allow search indexing and appear in the sitemap. Detailed product pages with outstanding specification reviews and thin Blog category archives retain noindex. A sitemap is available; this does not mean Google has indexed the site or that Search Console submission has occurred.

The factory gallery contains 12 unique supplied photographs optimized for the web. The document library contains all 13 supplied document pages in 9 groups. Full document images are unchanged copies. Displayed dates and scopes are transcribed from the supplied documents; registry status has not been independently verified. CQC20703258978 is explicitly archived because its printed period ended on 2026-07-30.
